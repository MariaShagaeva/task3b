## Реализовано

**Интерфейс.**
Кнопка «Загрузить пользователей», подписанное поле «Поиск по имени», список
пользователей, отдельная область публикаций, область сообщений.

**Загрузка пользователей (GET).**
По нажатию на кнопку выполняется `fetch` к `https://jsonplaceholder.typicode.com/users`.
Проверяется `response.ok`, данные рендерятся через `textContent`
(имя, email, город).

**Поиск по имени.**
Фильтрация уже загруженного массива `allUsers` без нового HTTP-запроса.
Регистр не учитывается (`toLowerCase()`). При отсутствии совпадений выводится
сообщение «Пользователи не найдены».

**Публикации пользователя (GET).**
Кнопка «Показать публикации» на каждой карточке отправляет запрос
`https://jsonplaceholder.typicode.com/posts?userId=ID`. В отдельной области
выводятся заголовки и тексты первых трёх публикаций.

**Обработка ошибок и состояний.**
Используется `try/catch/finally`. Кнопки блокируются на время запроса,
в области сообщений отображается «Загрузка...». При ошибке (например, 404 при
замене `/users` на `/userz`) выводится красное сообщение, кнопка снова
становится активной — можно повторить попытку.

| Возврат правильного адреса                    | Повторный запрос работает              |
